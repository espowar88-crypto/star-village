# 별이 사라진 마을 (웹 주소용)

장애이해교육 게임 「별이 사라진 마을 : 길의 별」의 휴대폰·태블릿용 파일입니다.
이 가지(gh-pages)는 GitHub Pages로 열리며, 파일은 모두 `build.py`가 자동으로 만든 것입니다.

- 웹 주소: https://espowar88-crypto.github.io/star-village/
- 휴대폰·태블릿: 주소를 열고 「홈 화면에 추가」 → 한 번 연 뒤에는 인터넷 없이도 실행
- PC·전자칠판: 한 파일 버전(`별이사라진마을_프로토타입1.html`)을 쓰세요
- 교사용 설정: ESC 키, 또는 화면 왼쪽 위 구석을 3초 누르기

사용한 소리·그림: Kenney(CC0), OpenGameArt(CC0), Pixabay(Pixabay 라이선스), 글꼴 Jua·Gowun Dodum(SIL OFL).
