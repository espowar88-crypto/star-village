휴대폰·태블릿·전자칠판에서 게임을 화면 가득 하는 방법

안드로이드아이폰·아이패드PC·전자칠판

어떤 방법으로 할까요?

안드로이드앱 파일 설치를 추천해요. 켜자마자 가로 전체 화면이 되고 인터넷이 없어도 돼요.
아이폰·아이패드홈 화면에 추가해서 써요. 사파리 주소창 없이 게임만 열려요.
PC·전자칠판게임 파일(html) 하나를 열거나 웹 주소로 들어가요.

게임 웹 주소: https://espowar88-crypto.github.io/star-village/

안드로이드추천: 앱 파일

갤럭시 등 안드로이드 휴대폰·태블릿 (안드로이드 6 이상)

앱 파일로 설치하기

앱 파일 받기 (68MB)
  1. 이 안내 페이지를 휴대폰 크롬에서 열고 위의 앱 파일 받기를 눌러요.
  2. "이 파일은 유해할 수 있습니다"라고 물으면 다운로드를 눌러요.
  3. 다 받으면 아래에 뜨는 열기를 눌러요. (못 봤다면 내 파일의 다운로드에서 파일을 눌러요.)
  4. "출처를 알 수 없는 앱" 화면이 나오면 설정을 누르고 이 출처 허용을 켠 뒤 뒤로 가요.
  5. 설치를 눌러요. Play 프로텍트 창이 뜨면 세부정보 더보기, 무시하고 설치를 차례로 눌러요.
  6. 홈 화면의 별의 스펙트럼 아이콘을 눌러 시작해요. 저절로 가로 전체 화면이 돼요.

화면 가장자리를 밀면 아래 버튼 줄이 잠깐 나왔다가 다시 숨어요.

새 판이 나오면 같은 방법으로 새 앱 파일을 설치하면 돼요. 저장한 기록은 그대로 남아요. 앱을 삭제하면 기록도 지워지니 지우지 말고 덮어 설치해 주세요.

앱 파일 없이 하기 (웹 앱)

  1. 크롬에서 게임 웹 주소를 열어요.
  2. 오른쪽 위 점 세 개 메뉴에서 앱 설치 또는 홈 화면에 추가를 눌러요.
  3. 홈 화면의 아이콘으로 켜요.

삼성 인터넷의 "바로가기"로 추가하면 위아래 줄이 남을 수 있어요. 꼭 크롬에서 추가해 주세요.

아이폰·아이패드홈 화면에 추가

아이폰은 앱 파일을 설치할 수 없어서 웹 앱으로 써요.

  1. 사파리에서 게임 웹 주소를 열어요. (크롬 앱이 아니라 사파리예요.)
  2. 아래쪽(아이패드는 위쪽) 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  3. 목록을 내려 홈 화면에 추가를 눌러요.
  4. 웹 앱으로 열기가 보이면 켜 둔 채로 오른쪽 위 추가를 눌러요.
  5. 사파리를 닫고, 홈 화면의 별의 스펙트럼 아이콘으로 켜요.
  6. 휴대폰을 가로로 들어요. 주소창과 시계 줄 없이 게임이 화면에 가득 차요.

화면 회전 잠금이 켜져 있어 세로로만 보여도 괜찮아요. 게임 화면이 저절로 옆으로 돌아가니 휴대폰을 옆으로 돌려 들면 돼요.

소리가 안 나면 휴대폰 옆의 무음 스위치를 확인해 주세요.

처음 한 번은 인터넷이 필요해요. 한 번 열고 나면 인터넷 없이도 돼요.

PC·전자칠판

게임 파일로 하기

  1. 선생님께 받은 게임 파일(별이사라진마을_소리의별.html)을 바탕화면에 두어요.
  2. 파일을 두 번 눌러 크롬이나 엣지로 열어요.
  3. 키보드 F11을 누르면 전체 화면이 돼요. 한 번 더 누르면 돌아와요.

웹 주소로 하기

  1. 크롬이나 엣지에서 게임 웹 주소를 열어요.
  2. 주소창 오른쪽의 설치 아이콘을 누르면 바탕화면에 앱처럼 깔려요.

선생님 설정은 ESC 키, 휴대폰·태블릿은 왼쪽의 설정 버튼으로 열어요.

알아 두면 좋아요

저장기록은 그 기기, 그 앱 안에만 저장돼요. 앱 파일과 웹 앱, 사파리와 홈 화면 앱은 기록을 따로 가져요.
새 판웹 앱은 인터넷에 연결되면 저절로 새 판으로 바뀌어요. 앱 파일은 새 파일을 다시 설치해요.
예전 판이 계속 뜰 때홈 화면 아이콘을 지우고 다시 추가해요. (기록이 지워질 수 있으니 주의해 주세요.)
