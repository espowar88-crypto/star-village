「별의 스펙트럼」 제목 연출 기획안 v1.0 (2026-10-01)

이번에는 기획과 그림 프롬프트까지. 게임 코드는 선생님 확인 뒤에 바꿉니다.

1. 핵심 생각

  • 스펙트럼 = 한 빛이 여러 빛깔로 나뉜 것. 우리 별 9개는 모양도 색도 하는 일도 모두 다릅니다. 여덟 빛깔이 모여 무지개가 되고, 그 위에 크림빛 "마지막 별"이 빛납니다.
  • 전하는 말: "모두 다르지만, 모두 있어야 무지개가 된다."
  • 이야기와 이어지기
    • 제목 화면 = 별이 다 있던 행복한 마을의 하늘 (빛깔이 모두 있음)
    • 인트로 C1 = 그 빛깔이 하나둘 사라짐
    • 게임 = 빛깔을 하나씩 되찾음
    • 엔딩 = 제목 화면의 무지개가 다시 완성됨

무지개 띠 색 (바깥부터, 별 색 그대로): 말 분홍, 마음 주황, 속도 금빛, 함께 노랑, 문턱 초록, 생각 민트, 길 하늘색, 소리 보라.

2. 제목 화면 장면 (처음 약 9초, 누르면 바로 마지막 모습)

장면 시간 보이는 것과 움직임 소리
T1 물감 밤하늘 0~1.5초 빈 종이에 남색 물감이 가장자리에서 안쪽으로 번져 밤하늘이 됨. 아래 마을 창문에 불이 하나씩 켜짐 없음
T2 마지막 별 1.5~3초 가운데 위에 크림빛 큰 별이 천천히 밝아짐 (번쩍이지 않게 1.5초 동안) 없음
T3 빛깔이 나뉨 3~6초 마지막 별 아래로 무지개 띠가 왼쪽부터 물감 번지듯 펼쳐짐. 띠 위에 별 8개가 왼쪽부터 하나씩 톡 앉음 없음
T4 제목 6~8.5초 "별의 스펙트럼" 글자가 붓으로 칠하듯 왼쪽부터 채워짐. 글자 속은 여덟 빛깔 물감. 아래 장식 선과 작은 글씨 "길의 별" 없음
T5 기다림 8.5초부터 계속 별이 아주 천천히 둥실, 무지개가 느리게 일렁임, 루미가 둥실. [시작하기] 버튼이 부드럽게 나타남 없음
T6 시작하기 누름 2초 하프가 별마다 한 음씩 올라가고(도레미...), 이야기꾼이 "별의 스펙트럼." 하고 읽어 줌. 무지개가 별 속으로 스며들고 별 9개가 C1 첫 장면 자리로 미끄러지며 어두워짐 하프 9음, 제목 음성, 제목 음악 시작
  • 처음 열 때는 브라우저 규칙상 누르기 전에는 소리를 낼 수 없어, T1~T5는 그림만 움직이고 소리는 T6부터 나옵니다.
  • T6 다음은 지금처럼 저장 칸 고르기, 이름, "제 1장"이고, C1 첫 장면이 같은 밤하늘과 같은 별 자리로 시작해 "옛날 옛날, 별빛 마을이 있었어요"로 자연스럽게 이어집니다.

3. 인트로·게임과 이어지게 (작게 바꾸기)

  1. 같은 별 자리: T6에서 별이 C1의 별 자리로 옮겨 가므로 C1 코드는 고치지 않아도 이어집니다.
  2. 이어 하기 제목 화면 = 진행판 (추천): 되찾은 별만 색이 있고, 나머지는 회색으로 흐리게. 무지개 띠도 되찾은 빛깔만 칠해짐. 9개를 다 찾으면 처음 제목 화면 그대로.
  3. 엔딩 뒤: 마지막 별까지 찾으면 제목 화면이 T3~T4를 한 번 더 보여 주며 끝납니다 (나중 일, 9번째 별 때).

4. 지킬 것

  • 번쩍임 없음: 밝아지는 것은 모두 0.5초보다 천천히. 화면 전체가 한꺼번에 밝아지지 않음.
  • 건너뛰기: 아무 곳이나 누르면 바로 T5. 같은 기기에서 두 번째부터는 짧은 판(약 3초).
  • 움직임 줄이기(교사 설정, 기기 설정): 움직임 없이 T5 모습만.
  • 글꼴: 제목 글자도 배민 주아체. 글자 모양은 게임이 쓰고 속만 물감 그림으로 채움. 이모지, 코드 그림 없음.
  • 화면 비율: 16:9 기준. 휴대폰은 하늘을 위아래로 늘리고, 글자와 버튼은 가운데 고정.

5. 제목을 바꿀 곳 (반영 단계)

  • 게임 제목 글자, 불러오는 중 글, 홈 화면 앱 이름, 홈 화면 아이콘 (app_icon 그림).
  • 웹 주소(star-village)와 파일 이름은 그대로 둡니다. 바꾸면 휴대폰 홈 화면 아이콘과 저장이 끊깁니다.
  • 시작 화면 코드는 「방탈출 요소 더하기」 스레드가 맡고 있어, 반영할 때 그쪽과 겹치지 않게 순서를 맞춥니다.
